Die auf dieser Website verwendeten Schriftarten werden lokal vom eigenen Server ausgeliefert. Beim Seitenaufruf wird keine Verbindung zu Servern von Google oder anderen Schriftanbietern aufgebaut.

Speicherung im Browser (Local Storage)

Diese Website speichert ohne Einwilligung nur Angaben, die für einen von Ihnen ausdrücklich gewünschten Dienst unbedingt erforderlich sind (§ 25 Abs. 2 Nr. 2 TDDDG). Dazu nutzt sie den lokalen Speicher Ihres Browsers (Local Storage); diese Einträge werden nicht an den Server übertragen:
